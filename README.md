# Блог-платформа

Готовый учебный проект на Python + Flask + SQLite.

## Запуск

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

## Администратор

- Логин: `admin`
- Пароль: `admin123`

После первого запуска создаётся файл `blog.db`. Для реального проекта обязательно замените пароль и `SECRET_KEY`.

## Реализовано

- регистрация и авторизация;
- хеширование паролей;
- лента постов;
- пагинация;
- поиск;
- фильтр по категориям и тегам;
- создание, редактирование и удаление своих постов;
- комментарии;
- лайки;
- категории и теги;
- админ-панель;
- бан/разбан пользователей;
- удаление постов и комментариев администратором;
- статистика пользователей, постов, комментариев и лайков.
